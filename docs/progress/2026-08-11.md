# Progress — 2026-08-11

## Decisions

- Initialized an independent repository on `develop`; no source repository is
  being rewritten to consume it during extraction.
- Kept RPS_SDK as the ROCK provider ABI repository.
- Accepted existing in-code/in-game-proven engine claims without redundant blind
  verification, per user instruction.
- Chose a dependency-free foundation so incorrect CommonLibF4VR layouts and
  relocations cannot leak into the new public contract.
- Chose static-link libraries rather than a mandatory shared runtime DLL.

## Implemented in the sixteenth batch

- Added a consumer-owned collision-pair suppression snapshot with 256 fixed
  rule slots. Rules symmetrically match layers, groups, combined layer/group
  endpoints, or one constrained endpoint against any opposing filter.
- Publication canonicalizes endpoint order, removes duplicates, rejects fully
  unconstrained rules, reports truncation/invalid input, and records a caller
  generation without allocating.
- Writers serialize behind one mutex and publish through an odd/even atomic
  sequence. Physics readers use only fixed atomic storage; they recheck the
  sequence after scanning and fail open to the original collision result if a
  writer overlapped the read.
- Evaluation accepts the already-computed vanilla result and can only suppress
  `true` to `false`; it cannot manufacture a collision the engine rejected.

- Added the trusted 15-byte `bhkCollisionFilter::CompareFilterInfos` entry
  prefix beside the cataloged `0x1E115B0` RVA. The framework supplies identity
  preflight data but intentionally does not allocate a trampoline or install a

  explicit consumer owner.

## Implemented in the twenty-second batch

- Added dependency-free wrappers for the FO4VR `NiNode` attach-child and
  detach-child virtuals at slots `0x3D` and `0x40`, using the verified child
  parent link at `+0x28`.
- Parent and child must each already carry a caller-owned live Bethesda/Ni
  reference. The wrapper takes temporary references across the native call,

  another non-null parent fails without implicit reparenting. Detach requires
  an exact parent match.
- Every result records the before/after parent, virtual target, invocation, and
  temporary-reference outcomes. Native faults remain distinct even if the
  observed postcondition changed, avoiding a false rollback claim.
- Hierarchy calls require the exact runtime and owner thread outside physics;
  invalid pointers, missing live references, unavailable virtual targets, and
  failed postconditions all fail distinctly.

  and complete 44-test Release coverage pass.

## Implemented in the twenty-third batch
